## 🏕️ 서버 소개 및 컨셉

> **Everest**는 편안하고 즐겁게 야생을 즐길 수 있도록 마련된 **협동 친목 야생(Hard Survival)** 서버입니다.
>
> 너무 쉬운 난이도는 지루하니까! **어려움(Hard) 난이도**로 설정되어 적당한 긴장감을 선사하며,  
> 죽어도 영구 차단되지 않고 친구들과 함께 탐험하고, 거대한 건축물을 짓고, mcMMO로 스킬을 키워나가는 재미를 제공합니다.

---

## ⚡ 핵심 시스템 (Key Features)

### 🗡️ 1. 스릴 넘치는 어려움 난이도 (Hard Difficulty)
- **Hard 난이도**: 굶주림 시 체력이 바닥나며, 좀비가 문을 부수거나 몬스터의 데미지가 강력하여 협동의 중요성이 큽니다.
- **자유로운 리스폰**: 사망 시 밴이나 영구 관전 없이 침대/스폰 지점에서 다시 부활하여 친구들과 계속 모험을 이어갈 수 있습니다.

### ⚔️ 2. mcMMO 야생 성장 시스템
- 채광, 벌목, 낚시, 궁술, 검술, 길들이기 등 13가지 생존 기술을 연마하세요.
- 레벨이 오를수록 획득하는 특수 능력(트리 펠러, 기가 드릴, 광폭화 등)으로 작업 효율을 극대화할 수 있습니다.

### 🛡️ 3. 생존자 영토 보호 (GriefPrevention)
- 금 괭이/금 삽을 이용해 자신만의 안전가옥과 요새를 클레임(영역 보호)할 수 있습니다.
- 생존 시간과 mcMMO 활동에 따라 보호 가능한 블록 수가 점진적으로 증가합니다.

### 🌐 4. 완벽한 크로스플레이 (Java + Bedrock Support)
- **Java Edition (PC)** 뿐만 아니라 **Bedrock Edition (스마트폰, 태블릿, 콘솔, 윈도우 10)** 유저도 동일한 월드에서 함께 생존할 수 있습니다. (`Geyser` + `Floodgate`)

### 📈 5. 실시간 리더보드 & 스탯 (TAB & CoreProtect)
- Tab 화면에서 현재 생존 일수, K/D, 핑, 플레이어 스탯을 한눈에 확인할 수 있습니다.
- 모든 블록 및 상자 상호작용은 실시간 로깅되어 비인가 행위가 철저히 차단됩니다.

## ⌨️ 필수 명령어 (Quick Commands)

```bash
# 기본 편의 명령어
/spawn            # 서버 스폰 지점으로 이동
/tpa <플레이어>   # 해당 플레이어에게 텔레포트 요청 전송
/tpaccept         # 도착한 텔레포트 요청 수락
/sethome [이름]   # 현재 위치를 집으로 설정 (하드코어 밸런스에 맞춰 쿨타임 적용)
/home [이름]      # 설정된 집으로 이동

# mcMMO 스킬 명령어
/mcstats          # 자신의 mcMMO 전체 스킬 레벨 및 랭킹 확인
/<스킬명>         # 특정 스킬의 세부 정보 확인 (예: /mining, /swords)
/mctop [스킬]     # 서버 전체 스킬 랭킹 확인

# 영역 보호 (GriefPrevention)
/claim            # 현재 서 있는 블록 주변을 보호 영역으로 생성
/trust <플레이어> # 대상 플레이어에게 내 영역 내 건축/상자 권한 부여
/untrust <플레이어># 대상 플레이어의 권한 회수
/abandonclaim     # 현재 밟고 있는 클레임 삭제
```

## 🛠️ 서버 구동 및 관리 (Server Management)

본 서버는 Termux / Linux 환경에서 **자동 tmux 백그라운드 구동 컨트롤러**와 **Aikar's G1GC 최적화 플래그**로 작동합니다.

### 🎮 서버 제어 명령어 (Controller Commands)
```bash
./start.sh          # 백그라운드(tmux)로 서버 자동 시작
./start.sh console  # 실시간 인게임 콘솔(tmux) 접속 (Ctrl+B, D 로 안전하게 빠져나오기)
./start.sh stop     # 청크 저장 후 안전하게 서버 종료
./start.sh restart  # 서버 재부팅
./start.sh status   # 서버 구동 상태, Java PID, RAM 점유율 확인
./start.sh logs     # 실시간 로그 스트리밍 (tail -f)
./start.sh cmd "명령어" # 쉘에서 바로 인게임 명령어 실행 (예: ./start.sh cmd say 안녕하세요)
```

### 🔄 PaperMC 자동 빌드 업데이트
```bash
./update.sh
```
> PaperMC Fill API v3를 연동하여 최신 빌드를 자동으로 검증(SHA-256) 및 다운로드합니다.
