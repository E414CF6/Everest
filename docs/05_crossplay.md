# 📱 Java & Bedrock 크로스플레이 가이드 (Crossplay Guide)

> **"PC 자바 에디션부터 스마트폰, 닌텐도 스위치, 콘솔까지 모든 플랫폼에서 함께 생존하세요."**

---

## 🌐 1. 크로스플레이 개요

Everest 서버는 **GeyserMC** 및 **Floodgate** 기술을 적용하여 자바 에디션(Java Edition)과 베드락 에디션(Bedrock Edition) 유저가 단 하나의 월드에서 실시간으로 함께 플레이할 수 있습니다.

---

## 💻 2. 플랫폼별 접속 설정

### 🖥️ 1) Java Edition (PC)
1. 마인크래프트 실행 ➔ **멀티플레이 (Multiplayer)** ➔ **서버 추가 (Add Server)**
2. **서버 주소**: `everest.mc` (또는 지정된 서버 IP)
3. **포트**: `25565` (기본값이므로 생략 가능)
4. 완료 후 서버에 접속합니다.

---

### 📱 2) Bedrock Edition (모바일 Android / iOS / Windows 10/11)
1. 마인크래프트 실행 ➔ **플레이 (Play)** ➔ **서버 (Servers)** 탭 선택
2. 맨 아래로 스크롤하여 **서버 추가 (Add Server)** 클릭
3. 정보 입력:
   - **서버 이름**: `Everest MC`
   - **서버 주소**: `everest.mc` (또는 지정된 서버 IP)
   - **포트 (Port)**: `19132` (베드락 기본 포트)
4. 저장 후 서버에 접속합니다.

---

### 🎮 3) 콘솔 (Nintendo Switch / PlayStation / Xbox) 접속
콘솔 기기는 기본적으로 외부 서버 추가 메뉴가 제한되어 있으므로 다음 방법 중 하나를 이용합니다:

- **스마트폰 앱 활용 (추천)**:
  - 스마트폰에 `BedrockTogether` 또는 `MC Server Connector` 앱을 설치합니다.
  - 앱에서 서버 IP와 포트(`19132`)를 입력하고 'Run'을 누릅니다.
  - 콘솔 마인크래프트의 '친구 (Friends)' 탭의 LAN 게임 목록에 Everest 서버가 나타납니다.
- **DNS 설정 변경**:
  - 인터넷 설정에서 DNS를 `104.238.130.180` (BedrockConnect)으로 지정 후 서버 목록 진입.

---

## ⚙️ 3. 베드락 유저 전용 안내 및 조작 팁

1. **베드락 닉네임 표기**:
   - Floodgate 연동으로 인해 베드락 유저는 닉네임 앞에 접두사(예: `.` 또는 `*`)가 자동으로 붙을 수 있습니다.
   - 명령어 입력 시 전체 닉네임을 사용해야 합니다. (예: `/tpa .Steve123`)

2. **GUI / 폼 메뉴 호환**:
   - CMI 및 플러그인의 GUI 상자 메뉴는 베드락 전용 폼(Form) UI로 자동 변환되어 터치스크린으로 편리하게 터치 조작할 수 있습니다.

3. **전투 쿨다운 시스템**:
   - 자바 1.9+ 전투 시스템(공격 쿨다운 게이지)이 적용되어 있으므로, 연속으로 터치하여 때리는 것보다 게이지가 다 찼을 때 타격하는 것이 더 높은 데미지를 줍니다.
