# ⌨️ 플레이어 명령어 백과사전 (Commands Reference)

> **"Everest 서버에서 생존과 모험에 필수적인 전체 명령어 가이드입니다."**

---

## 🌟 0. 올인원 메인 메뉴 & 한글 단축어 (Main Menu & Shortcuts)

모든 기능을 한눈에 보고 터치/클릭할 수 있는 메뉴와 직관적인 한글 단축어를 지원합니다.

| 명령어 / 단축어 | 설명 | 비고 |
| :--- | :--- | :--- |
| **`/메뉴`**, **`/menu`**, **`/m`** | **올인원 메인 메뉴 다이얼로그 호출** | 야생이동, 집, 스킬, 스탯, 영토, 쓰레기통 통합 |
| `/집` [이름], `/홈` | `/home` 단축어 (저장된 집으로 이동) | |
| `/집설정` [이름] | `/sethome` 단축어 (현재 위치를 집으로 저장) | |
| `/집목록` | `/homes` 단축어 (저장된 내 집 목록 확인) | |
| `/야생`, `/이동`, `/rtp` | 야생 무작위 텔레포트 다이얼로그 호출 | |
| `/요청 <친구>` | `/tpa <친구>` 단축어 (친구에게 이동 요청) | |
| `/수락`, `/거절` | `/tpaccept`, `/tpdeny` 단축어 | |
| `/스탯`, `/정보` | 플레이어 상세 통계 다이얼로그 호출 | |
| `/스킬` | mcMMO 13종 스킬 현황 다이얼로그 호출 | |
| `/클레임`, `/보호` | 영토 보호 관리 다이얼로그 호출 | |
| `/공유 <친구>` | 친구에게 내 영토 신뢰(`/trust`) 부여 | |
| `/쓰레기통`, `/휴지통` | 가방에 찬 불필요한 아이템 버리기 창 오픈 | |
| `/돈`, `/지갑` | 내 잔고 확인 | |
| `/보내기 <친구> <금액>` | 친구에게 돈 송금 | |
| `/앉기`, `/눕기` | 바닥이나 블록에 앉기/눕기 | |

## 🏃 1. 이동 및 텔레포트 (Teleportation & Travel)

| 명령어 | 설명 | 비고 |
| :--- | :--- | :--- |
| `/spawn` | 서버 중앙 스폰 지점으로 이동합니다. | 전투 중 사용 불가 |
| `/tpa <플레이어>` | 대상 플레이어에게 텔레포트 요청을 보냅니다. | 상대방의 수락 필요 |
| `/tpahere <플레이어>` | 대상 플레이어를 내 위치로 텔레포트 요청합니다. | 상대방의 수락 필요 |
| `/tpaccept` | 수신된 텔레포트 요청을 수락합니다. | |
| `/tpdeny` | 수신된 텔레포트 요청을 거절합니다. | |
| `/sethome [이름]` | 현재 서 있는 위치를 집(Home)으로 저장합니다. | 최대 슬롯 수 제한 적용 |
| `/home [이름]` | 저장된 집으로 즉시 이동합니다. | 쿨타임 적용 |
| `/delhome <이름>` | 저장된 집 목록에서 해당 위치를 삭제합니다. | |
| `/back` | 이전 위치(사망 지점 또는 텔레포트 직전)로 되돌아갑니다. | 하드코어 설정에 따름 |

## ⛏️ 2. mcMMO 성장 및 스킬

| 명령어 | 설명 |
| :--- | :--- |
| `/mcstats` | 자신의 13종 전체 mcMMO 스킬 레벨과 누적 파워 레벨을 조회합니다. |
| `/mcrank` | 서버 내 자신의 스킬 순위를 확인합니다. |
| `/mctop [스킬명]` | 특정 스킬의 서버 최고 랭킹 Top 10을 확인합니다. |
| `/<스킬명>` | 해당 스킬의 액티브 쿨타임, 패시브 해금 현황을 상세 조회합니다. (예: `/mining`, `/swords`, `/acrobatics`) |
| `/mcability` | 도구 우클릭 시 발동되는 액티브 스킬 기능을 켜거나 끕니다. |
| `/inspect <플레이어>` | 가까이 있는 다른 플레이어의 스킬 레벨을 조사합니다. |

## 👥 3. 파티 (Party) 시스템

| 명령어 | 설명 |
| :--- | :--- |
| `/party create <이름>` | 새로운 모험 파티를 창설합니다. |
| `/party invite <플레이어>` | 특정 플레이어에게 파티 가입 초대를 보냅니다. |
| `/party accept` | 파티 가입 초대를 수락합니다. |
| `/party leave` | 현재 소속된 파티에서 탈퇴합니다. |
| `/party info` | 현재 파티원 목록 및 공유 경험치 상태를 조회합니다. |
| `/p <메시지>` | 파티원들만 볼 수 있는 파티 전용 비공개 채팅을 전송합니다. |

## 🏰 4. 영토 보호 (GriefPrevention Claims)

| 명령어 | 설명 |
| :--- | :--- |
| `/claim` | 현재 서 있는 위치 주변을 기본 영역으로 보호 설정합니다. |
| `/trust <플레이어>` | 대상 플레이어에게 건축/파괴/상자 등 전체 권한을 부여합니다. |
| `/containertrust <플레이어>` | 대상 플레이어에게 상자/화로/인벤토리 열람 권한만 부여합니다. |
| `/accesstrust <플레이어>` | 대상 플레이어에게 문/레버/버튼 사용 권한만 부여합니다. |
| `/permissiontrust <플레이어>` | 대상 플레이어에게 다른 사람을 신뢰 등록할 수 있는 권한을 줍니다. |
| `/untrust <플레이어>` | 대상 플레이어의 모든 권한을 취소합니다. |
| `/abandonclaim` | 현재 서 있는 클레임 영역을 삭제하고 블록을 환불받습니다. |
| `/claimslist` | 자신이 소유한 모든 클레임 좌표 목록과 남은 블록 수를 확인합니다. |

## 💬 5. 커뮤니케이션 & 기타 편의

| 명령어 | 설명 |
| :--- | :--- |
| `/msg <플레이어> <내용>` | 특정 플레이어에게 귓속말을 보냅니다. (동의어: `/w`, `/tell`) |
| `/r <내용>` | 가장 최근에 귓속말을 보낸 상대에게 빠르게 답장합니다. |
| `/ping` | 서버와 자신의 현재 네트워크 핑(ms) 상태를 확인합니다. |
| `/rules` | 서버 기본 규칙을 다시 확인합니다. |
| `/help` | 서버 도움말 메뉴를 호출합니다. |
